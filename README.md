# BLUE COLLECTOR

**AI와 함께 만든 웹 아케이드 게임**

30초 동안 노란 아이템을 모으고 빨간 추적자를 피하며 높은 점수를 얻는 게임입니다.

플레이어는 안전 모드와 전쟁 모드 중 하나를 선택할 수 있습니다. 전쟁 모드에서는 추가 점수를 얻을 수 있지만, 아이템을 먹을수록 적의 추적 속도가 빨라집니다.

프로그래밍을 배운 적 없는 상태에서 AI로 게임 코드를 만들었습니다. 게임을 직접 플레이하면서 규칙과 화면 구성을 여러 차례 수정했습니다.

**[BLUE COLLECTOR 플레이하기](https://moontaku.github.io/blue-collector/)**

별도의 설치 없이 PC 웹브라우저에서 실행할 수 있습니다.

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 장르 | 아케이드 / 수집 / 생존 |
| 플레이 시간 | 1회 최대 30초 |
| 플랫폼 | PC 웹브라우저 |
| 개발 환경 | HTML, CSS, JavaScript, Canvas |
| 개발 방식 | AI로 코드 작성, 직접 플레이하며 테스트 |
| 프로젝트 형태 | 개인 프로젝트 |

## 2. 조작 방법

- **W / A / S / D:** 캐릭터 이동
- **SPACE:** 안전 모드와 전쟁 모드 전환
- **목표:** 추적자를 피하면서 노란 아이템을 모아 높은 점수 얻기

## 3. 주요 게임 시스템

### 안전 모드와 전쟁 모드

**안전 모드**
- 기본 점수 획득
- 적의 기본 추적 속도 유지

**전쟁 모드**
- 아이템 획득 점수의 50%를 추가 보너스로 적립
- 아이템을 획득할 때마다 적의 추적 속도 5% 증가 (최대 25%)
- 아이템 획득 후 2초를 생존해야 안전 모드로 복귀 가능
- 안전 모드로 돌아오거나 30초를 완주하면 적립한 보너스 확정
- 보호막 없이 적과 충돌하면 확정되지 않은 보너스 손실

### 콤보 시스템

4초 안에 다음 아이템을 먹으면 콤보가 이어집니다. 콤보가 쌓이면 최대 3배의 점수를 얻을 수 있습니다.

### 코인과 보호막

- 게임이 끝나면 기본 획득 점수만큼 코인 지급
- 코인으로 1회용 보호막 구매 가능
- 보호막은 전쟁 모드에서 적과 충돌했을 때만 발동
- 보호막 발동 시 충돌 1회를 막고 1초 동안 무적 상태 유지

### 개인 기록과 도전 과제

최고 점수, 최고 콤보, 누적 플레이 횟수와 도전 과제를 확인할 수 있습니다.

일부 기록과 보유 재화는 브라우저의 로컬 저장소에 저장됩니다.

## 4. AI와 함께 게임을 만든 과정

이 프로젝트를 시작하기 전에는 프로그래밍 경험이 없었습니다. 게임의 규칙과 필요한 기능을 정하고, AI에 코드 작성을 요청하는 방식으로 개발했습니다.

**직접 한 일**
- 게임 콘셉트와 기본 규칙 기획
- 안전 모드와 전쟁 모드의 보상 및 위험 구조 설계
- 기능별 요구사항 정리
- AI가 작성한 코드를 실행하고 작동 여부 확인
- 직접 플레이하면서 오류와 불편한 부분 기록
- 수정 방향 결정 및 재테스트

**AI가 도운 작업**
- HTML, CSS, JavaScript 코드 작성 및 수정
- 오류 원인 분석과 수정 방법 제안
- UI 코드 작성과 수정

처음부터 모든 기능을 만들지는 않았습니다.

캐릭터 이동과 아이템 수집부터 시작해 적의 추적, 콤보, 전쟁 모드, 상점, 보호막을 차례로 추가했습니다.

기능을 추가할 때마다 직접 플레이해 문제를 찾고, 코드를 수정한 뒤 다시 테스트했습니다.

## 5. 플레이 테스트와 수정 사례

### ① 적의 추적 속도와 난이도

초기 테스트에서 적이 느리게 움직일 때 오히려 아이템을 먹기 어려운 상황을 발견했습니다.

적이 아이템 근처에 오래 머물면서 수집을 방해했기 때문입니다.

추적 속도가 빠르다고 반드시 아이템을 먹기 어려운 것은 아닐 수 있다고 생각해 추가 테스트를 했습니다.

하지만 테스트 결과가 일정하지 않았습니다. 따라서 추적 속도와 체감 난이도 사이의 관계는 아직 확인되지 않은 가설로 남겨두었습니다.

### ② 보호막과 무적 시간

보호막은 적과 충돌했을 때 한 번 살아남도록 만든 아이템입니다.

그런데 직접 플레이해 보니, 보호막이 발동한 1초 동안 평소보다 적극적으로 아이템을 수집하게 됐습니다.

반대로 무적 상태가 끝나는 순간 적과 충돌해 게임이 종료되는 경우도 있었습니다.

처음에는 무적 시간이 끝나기 직전에 캐릭터가 깜빡이도록 만들었습니다.

하지만 1초라는 짧은 시간에 깜빡임까지 더해지니 화면이 정신없게 느껴졌습니다.

이후 깜빡임을 없애고 보호막을 나타내는 링이 서서히 사라지도록 수정했습니다.

### ③ 게임 화면의 가독성

플레이 테스트 중 콤보 메시지가 안전 모드와 전쟁 모드 정보를 표시하는 박스에 겹치는 문제를 발견했습니다.

콤보 메시지의 중앙 정렬은 유지하고, 위치를 아래로 28px 옮겼습니다.

또한 위험도 진행 바가 UI 카드의 둥근 모서리 밖으로 튀어나오는 문제도 발견했습니다.

진행 바가 카드 밖으로 보이지 않도록 CSS를 수정하고 화면을 다시 확인했습니다.

## 6. 개발 결과와 회고

AI로 첫 게임 코드를 만든 뒤 적의 추적, 전쟁 모드, 콤보, 상점과 보호막 등의 기능을 추가했습니다.

이후 플레이 테스트를 거쳐 UI와 게임 규칙을 수정했고, 완성한 게임을 GitHub Pages에 배포했습니다.

처음 정한 게임 규칙도 직접 플레이해 보니 예상과 다르게 작동하는 부분이 있었습니다.

특히 보호막을 사용했을 때 플레이 방식이 달라지는 점이나, 적의 추적 속도가 아이템 획득에 미치는 영향은 게임을 직접 실행하면서 발견한 문제였습니다.

게임을 만드는 동안 기능이 정상적으로 작동하는지뿐 아니라, 실제로 플레이했을 때 어떤 경험을 주는지도 함께 확인했습니다.
